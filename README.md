## About This Repository

This repository contains the Continuous Lab Evaluation (CAT) experiments performed as part of the **Foundations of Internet of Things + Lab** course at Shiv Nadar University, Chennai.

The experiments cover embedded systems programming and peripheral interfacing using the **8051 Microcontroller** and **STM32 Microcontroller**.

Each CAT experiment is organized into a separate folder containing the relevant source code, project files, circuit diagram, and experiment documentation.

## Experiment Documentation Format

Each CAT folder follows the documentation format specified in the reference repository.

### 1. Experiment Details
- EXP: Continuous Assessment Number
- DATE: Date of Experiment
- NAME OF EXP: Exact Experiment Name
- HARDWARE SETUP / PLATFORM: Development Board and Tools
- TASK NO: Task Identifier

### 2. Circuit Diagram
Circuit diagram showing the necessary microcontroller pins, peripheral connections, power supply, and clock configuration wherever applicable.

### 3. Core Logic / Pseudocode / Code Base
Explanation of the implementation approach, program logic, algorithms, and relevant source code.

### 4. Project Files
Required source files and project configuration files used for implementing the experiment.

### 5. Inference
Observations, results, and conclusions obtained from the experiment.

For experiments containing multiple tasks, each task is documented separately within the corresponding CAT folder.

## Repository Guidelines

1. Experiment and task names follow the official CAT question PDFs.
2. Circuit diagrams are included with the relevant experiments.
3. Source code and project files are organized according to the CAT number.
4. Unnecessary generated and temporary files are excluded.
5. Multiple tasks within the same experiment are identified using their respective task names.
6. Required project configuration and source files are retained for reproducibility.
